# ScamShield Dataset Schema

## Columns

| Column | Values | Notes |
|--------|--------|-------|
| `id` | `ss-000001` ... | Stable row id (assigned after dedup and split) |
| `text` | string | SMS / chat text. No real PII. |
| `language` | `en` `hi` `mr` `hinglish` | Best-effort language label |
| `scam_or_safe` | `scam` `safe` | Binary target |
| `scam_type` | see below | `safe` when `scam_or_safe` is `safe` |
| `source` | `synthetic_scamshield` or `hf_karanverma19` | Provenance of the row |
| `indicators` | `a|b|c` | Pipe-separated hint features for explainability |
| `split` | `train` `validation` `test` | Assigned once by stratified split; **do not retune on test** |

## `scam_type` values

| Value | Description |
|-------|-------------|
| `safe` | Legitimate message (not a scam) |
| `kyc` | Fake KYC expiry / update scams |
| `upi_payment` | Fraudulent UPI collect requests, fake refunds |
| `bank_impersonation` | Impersonating banks to steal OTP/PIN |
| `phishing` | Credential-harvesting links mimicking legitimate services |
| `customer_care` | Scammers posing as support staff |
| `job` | Fake job offers requiring fees or personal data |
| `investment` | Guaranteed-return or crypto schemes |
| `loan` | Fake pre-approved loans requiring upfront fees |
| `delivery` | Fake customs/courier payment demands |
| `lottery` | Fake prize notifications |
| `social_impersonation` | Impersonating relatives/contacts requesting money |
| `other` | Miscellaneous social-engineering (electricity, SIM, court, etc.) |

## `source` values

| Value | Description |
|-------|-------------|
| `synthetic_scamshield` | Generated by `scripts/build_dataset.py` using templates. Privacy-safe. |
| `hf_karanverma19` | Rows from the HuggingFace public dataset. Curated and filtered. |

## `indicators` values

Common indicator tags:

- `urgency` - message contains time pressure language
- `kyc_language` - references KYC or identity verification
- `suspicious_url` - contains or references a URL
- `otp_request` - requests OTP or PIN
- `payment_request` - requests payment or money transfer
- `bank_impersonation` - impersonates a bank
- `customer_care` - claims to be support/helpdesk
- `social_impersonation` - impersonates a known contact
- `job_offer` - offers employment
- `investment_return` - promises investment returns
- `loan_offer` - offers a loan
- `delivery_threat` - threatens delivery issues
- `prize_lottery` - claims a prize or lottery win
- `sensitive_info_request` - requests personal/financial information
- `none` - no suspicious indicators (safe messages)

## Privacy rules

Texts must use **placeholders only**:

| Placeholder | Meaning |
|-------------|---------|
| `[OTP]` | One-time password (redacted) |
| `[PHONE]` | Phone number (redacted) |
| `[ACCOUNT]` | Bank account number (redacted) |
| `[REF]` | UPI/payment reference (redacted) |
| `XX12` | Last 4 digits of account/card (masked) |
| `http://*.example.in` | Example URL domain |
| `192.0.2.x` | RFC 5737 TEST-NET (not routable) |

**Prohibited in dataset**:

- Real OTPs
- Real passwords
- Real bank account numbers
- Real card numbers
- Real phone numbers
- Real addresses
- Real authentication credentials
- Unnecessary personally identifiable information

Synthetic examples and legally usable public datasets are preferred.
