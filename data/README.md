# ScamShield Dataset

Labelled dataset for the Indian Digital Scam Intelligence & Prevention System (ScamShield) research project.

## Directory structure

| Path | Purpose |
|------|---------|
| `raw/` | Original public downloads (before processing) |
| `processed/messages.csv` | Full labelled table with train/val/test split assignments |
| `processed/summary.json` | Aggregate counts: by label, type, language, source, split |
| `train/messages.csv` | Training split (~70%) |
| `validation/messages.csv` | Validation split (~15%) |
| `test/messages.csv` | **Frozen** held-out test split (~15%) |

## What each dataset represents

- **`raw/ultra_premium_scam_dataset.csv`**: Public dataset from HuggingFace (karanverma19/Indian_Multilingual_Scam_Message_Dataset). Contains multilingual scam/safe messages in English, Hindi, and Hinglish. See `LICENCES.md` for licence details.

- **`processed/messages.csv`**: The combined, deduplicated, labelled dataset generated by `scripts/build_dataset.py`. Includes synthetic ScamShield messages (all 4 languages including Marathi) and curated rows from the public dataset. Each row has: `id`, `text`, `language`, `scam_or_safe`, `scam_type`, `source`, `indicators`, `split`.

- **`train/messages.csv`**: Used to train ML models. Models should never see the test set during training.

- **`validation/messages.csv`**: Used for hyperparameter tuning and early stopping during model development.

- **`test/messages.csv`**: **Frozen** held-out split. Must not be used for training or model selection. Used only for final evaluation reporting.

## Labeling concept

Each message is labelled with:

- `scam_or_safe`: binary label (`scam` or `safe`)
- `scam_type`: the specific scam category (or `safe` for legitimate messages)
- `language`: one of `en`, `hi`, `mr`, `hinglish`
- `indicators`: pipe-separated hint features (e.g., `urgency|kyc_language|suspicious_url`)

## Rebuilding the dataset

```bash
python scripts/build_dataset.py
```

This regenerates all splits from `raw/` and the synthetic templates in the script. The split assignment is deterministic (seed=42).

## Privacy

No real OTPs, phone numbers, bank accounts, card numbers, or private chats are stored. The dataset uses placeholders exclusively. See `schema.md` for the full privacy specification.
